EasyPay - Multibanco & MB WAY

Portuguese Payment Methods for EasyPay

This module extends the EasyPay payment provider to support Portugal's most popular payment methods:

  • Multibanco - ATM and online banking payments
  • MB WAY - Mobile payment solution

Features

Multibanco

  • Generate payment references
  • Accept payments via ATM
  • Accept payments via online banking
  • Automatic payment confirmation

MB WAY

  • Mobile payment integration
  • Push notifications to customer
  • Instant payment confirmation
  • Secure and convenient

Requirements

This module requires the payment_easypay module to be installed.

You must have an active EasyPay account with Multibanco and/or MB WAY enabled.
