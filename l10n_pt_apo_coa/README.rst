This module provides the Portuguese Chart of Accounts (COA) for the APO
localization package. It contains all the necessary accounting
structure, tax configurations, and fiscal positions required for
Portuguese companies to comply with local accounting standards.

The module includes:

-  Complete Portuguese chart of accounts with 3-digit coding system
-  Tax templates for mainland Portugal including VAT, withholding taxes,
   and stamp duties
-  Account groups following Portuguese classification standards
-  Fiscal positions for domestic and EU transactions
-  Integration with l10n_pt_certification for compliance requirements

This is the base chart of accounts module that can be used independently
or as part of the complete l10n_pt_apo localization suite.

Configuration
=============

After installation, you can create a new Portuguese company and the
chart of accounts will be automatically configured with:

-  Standard Portuguese account structure (3-digit codes)
-  Default tax configuration for mainland Portugal
-  Fiscal positions for domestic and EU transactions
-  Account groups with proper Portuguese coding

To configure the chart of accounts:

1. Go to Accounting -> Configuration -> Chart of Accounts
2. The Portuguese chart of accounts will be automatically loaded
3. You can customize accounts, taxes, and fiscal positions as needed

Dependencies
------------

-  \`l10n_pt_certification\`: Base Portuguese certification module

Usage
=====

This module is automatically installed when you install the main
Portugal Localization module (l10n_pt_apo). It can also be installed
independently if you only need the chart of accounts without the full
localization features.

For Portuguese Companies

When creating a new Portuguese company:

1. Set the country to Portugal
2. The Portuguese chart of accounts will be automatically configured
3. Taxes and fiscal positions will be set up according to Portuguese
   regulations
4. Account groups will follow the standard Portuguese classification

For Existing Companies

If you want to switch to the Portuguese chart of accounts:

1. Install the module
2. Go to Accounting -> Configuration -> Settings
3. Choose the Portuguese chart of accounts template
4. Follow the migration wizard to update your accounts

Known Issues

-  Currently supports mainland Portugal only
-  Future versions may include Madeira and Azores specific
   configurations
